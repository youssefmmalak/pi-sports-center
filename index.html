Pi Sports Center

Pi Sports Center is a personal Raspberry Pi dashboard built for a 5-inch display. It provides live sports information including Los Angeles Dodgers scores, schedules, game status, weather, and personal fantasy football information.

Yahoo Fantasy Sports integration is used only for read-only access to the owner's personal fantasy football league, matchup, roster, scores, projections, and player information.

This is a personal, non-commercial, single-user project.
